# Aprender JavaScript

Este repositorio contiene una serie de ejercicios y ejemplos prácticos para aprender JavaScript. Incluye implementaciones hechas por el profesor y por Stiven, organizadas en diferentes carpetas según los temas trabajados.

## Estructura del Proyecto

- **hecho por el profe/**: Contiene ejemplos y ejercicios proporcionados por el profesor.
- **hecho por Stiven/**: Ejercicios desarrollados por Stiven, aplicando los conceptos aprendidos.

Cada carpeta está numerada y contiene archivos:
- `index.html`: Página principal del ejercicio.
- `main.js`: Código JavaScript asociado.
- `style.css`: Estilos CSS aplicados (cuando corresponde).
- Otras carpetas como `componentes/` y `modulos/` contienen archivos adicionales según el tema.

## Requisitos

- Un navegador web moderno.
- Un editor de texto o IDE como Visual Studio Code.

## Instalación y Uso

1. Descargar o clonar el repositorio.
2. Abrir `index.html` de la carpeta correspondiente en un navegador.
3. Explorar y modificar los archivos JavaScript para entender el funcionamiento.
